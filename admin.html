① GitHubアクセスキーの設定

お店データはこのサイトのGitHubリポジトリ（kobari-kic/gohan-map）に保存されてるよ。追加・編集・削除するには、そこに書き込める「アクセスキー（トークン）」が必要。一度だけ作って、ここに貼り付けてね（このスマホ・ブラウザだけに保存され、他には送られないよ）。

  1. こちらのページを開く（GitHubへのログインが必要）
  2. 「Repository access」で「Only select repositories」→「gohan-map」を選ぶ
  3. 「Permissions」→「Repository permissions」→「Contents」を Read and write に変更
  4. 一番下の「Generate token」を押す
  5. 表示された文字列（ghp_ や github_pat_ で始まる）をコピーして、下に貼り付けて保存
